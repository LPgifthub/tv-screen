# TV Home

An ad-free home screen for the Google TV Streamer, in cream, forest green, chocolate and marble.

## Install or update (no computer needed)

1. On the Streamer, install **Downloader** from the Play Store.
2. Allow Downloader to install apps: Settings → Apps → Security & restrictions → Unknown sources → Downloader → on.
3. Open Downloader and enter:
   `https://github.com/LPgifthub/tv-screen/releases/latest/download/tv-home.apk`
4. Press **Install**. To update later, repeat step 3. Your settings stay put.

## Make the Home button open TV Home

Open TV Home → **Setup** → **Open Accessibility settings** → **TV Home – Home button** → switch on.
Then press Home on the remote. If it still opens Google's screen, note the "Last Google screen seen" line on the Setup page.

## To remove it

Switch the Accessibility setting off, then uninstall TV Home (Settings → Apps). Everything goes back to how it was.
